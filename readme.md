## version

### 1.0

- [x] 使用`puppeteer`获取 m3u8 文件地址信息
- [x] 使用`ffmpeg`下载视频文件并转换为 mp3 格式

> 基本实现下载功能, 但缺少交互内容及相关输出信息, `ffmpeg` 的下载方式过慢, 并且控制台输出难以捕获为进度

### 1.1

- [x] 使用`inquirer`添加选择交互
- [x] 使用`ora`、`picocolors`美化命令行输出提示
- [x] 使用`axios`、`cheerio`解析动漫页相关内容信息

> 优化信息输出部分, 使得具体下载内容变得可选, 对应下载的信息得以可见

### 1.2

- [x] 使用`m3u8-parser`解析 m3u8 文件内容, 通过拆分下载`ts`文件, 再组合为`ffmpeg`的输入内容, 加快资源下载的速度
- [x] 使用`fs-extra`清理和重命名文件, 输出`ffmpeg`的文件内容
- [x] 通过文件流对应事件实现下载进度的输出

> 加快了下载速度, 添加下载进度, 但存在`ts`资源请求超时。直接使用`fs`相关 API 处理文件夹删除时出现错误。

### 1.3

- [x] 重构项目由`js`调整为`ts`, 处理`tsconfig.json`相关配置及模块化问题
- [x] 使用`webpack`构建输出文件, 同步修改相关配置问题

> `js`转换为`ts`并没有花太多时间, 但在尝试使用`ts-node`直接运行时并不顺利, `tsc`编译过程中也存在一系列模块与配置项问题, 特别是使用`package.json`中的`imports`作别名导入时, 存在诸多痛点。编译后也因为模块标准问题无法直接输出为单一文件, 最后改用`webpack`继续作调整取得较为理想的结果。
